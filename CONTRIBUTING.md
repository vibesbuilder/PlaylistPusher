# Contributing

PlaylistPusher is currently developed by a single maintainer.

- **Bug reports and feature requests are welcome.** Please use [Issues](https://github.com/vibesbuilder/PlaylistPusher/issues/new/choose) – the forms ask for everything that helps, and you can attach your track list as a text file. English or German is fine.
- **Pull requests are not accepted at the moment.** If you have an improvement in mind, please describe it in a feature request instead.
- **Security issues:** please do not open a public issue – report them privately via [Report a vulnerability](https://github.com/vibesbuilder/PlaylistPusher/security/advisories/new).
